State at hand-over: demo artifact is **version 26** (https://claude.ai/artifact/VwKjocavn1C6CLWeme2DSA). `web/dist/` and `web/import/` are rebuilt from the same source. Nothing has been deployed to Cloudflare. No test servers or temp files are left running or in the folder.

## How the frontend is organised now
- Edit `web/src/app.js` (application), `web/src/head.html` (CSS), `web/sync.js` (login, database, files, mail read state). `web/source.html` is the frozen original, never edit it.
- `py build.py` (in `web/`) writes `dist/` (deploy to Cloudflare Pages), `import/` (local one-time legacy import only) and `demo/artifact.html` (shared prototype artifact; local data, no login).
- Tip learned the hard way: shell heredocs halve backslashes; write patch scripts with the Write tool, and avoid `\n` regexes in browser test scripts.
